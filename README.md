# 🚀 Project Overview

This project demonstrates a complete Real-Time Sales Analytics pipeline where customer orders are placed through a website, stored in PostgreSQL, and automatically visualized in Power BI.

The dashboard updates whenever new orders are inserted into the database.

---

# 🎯 Objective

Build an end-to-end Business Intelligence solution capable of monitoring sales in real time.
